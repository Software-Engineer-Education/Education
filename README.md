# Overview

This directory contains supplementary materials for reviewer comments related to the study on Agile and Continuous Integration (CI) in education. The materials include an introduction to the project background, supporting documents, CI-related assignments and tutorials, and presentation slides covering DevOps and CI results.

# File Structure

- `assignments_and_tutorials/`
  Contains CI-related assignments and tutorials, along with supporting reference materials.

- `CI_slides/`
  Contains slides and result materials related to DevOps and Continuous Integration.

- `Assignment_overview.docx`
  Provides an overview of the semester-long assignment structure, required deliverables, project constraints, instructional support, and the staged integration of CI activities.

- `Basic_assignments.docx`
  Contains representative assignment instructions covering project selection, user stories, software architecture and design, GitHub documentation, and Sprint retrospective reporting.
  
- `Agile-CI.docx`
  Supplementary document prepared in response to reviewer comments.

- `Clarifications on operational decisions.docx`
  Additional clarification document for reviewer comments.

- `Ethics Statement.docx`
  Supplementary ethics statement document.

- `project_summary.xlsx`
  Project summary spreadsheet used as supporting material.

- `Survey.docx`
  Supplementary survey-related document.

# Notes

All files in the root directory, except for the two folders listed above, are supplementary materials prepared to address reviewer comments.
